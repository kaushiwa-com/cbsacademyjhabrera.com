CBS Academy Jhabrera — Starter Website

Files:
- index.html: website content and mobile menu script
- style.css: colors, layout, responsive design

How to preview:
1. Keep index.html and style.css in the same folder.
2. Open index.html in a web browser.
3. Edit the text in index.html to add real subjects, notes, phone number and address.
4. Replace placeholder links (#contact) with actual PDF links when your study materials are ready.

Note:
- This is a static starter website. It does not yet upload or manage notes automatically.
- Google Fonts need an internet connection; fallback fonts are included.
- The contact email link needs a real email address added to href="mailto:".
